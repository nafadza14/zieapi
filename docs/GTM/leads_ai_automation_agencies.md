# Laporan Profil Real AI Automation Agencies dan Workflow Builders Global

Dokumen ini memuat daftar terverifikasi 12 agensi otomasi AI (AI Automation Agencies / AAA) dan workflow builders global yang aktif menjual solusi agen otonom. Setiap entitas dilengkapi data riil, spesialisasi teknis, serta analisis use case integrasi data produk Apizie (REST API dan MCP Server).

Produk Fokus: Apizie (https://zieapi.vercel.app dan https://zieapi.vercel.app/mcp)

## Daftar Profil Agensi dan Potensi Integrasi Apizie

### 1. TrueHorizon AI
* Website: https://truehorizon.ai/
* Kontak atau Founder: Milan Tahliani (CEO dan Cofounder), Kirill Zhadovich (CTO), thai@truehorizon.ai
* Wilayah Operasional: Global dan Amerika Serikat
* Spesialisasi: Enterprise AI agents dan agentic workflows berbasis n8n, automasi dokumen, voice agents, serta sistem riset korporat terukur.
* Tech Stack Utama: n8n, Python, LLM orchestration, custom UI
* Potensi Use Case Apizie: TrueHorizon merancang agen riset dan intelijen pasar untuk klien korporat berskala besar seperti Avalara. Melalui Apizie MCP Server, agen n8n mereka dapat langsung memanggil 1600+ endpoint data publik seperti berita terverifikasi, data finansial pasar, dan entitas bisnis hanya dengan satu API key tanpa kerumitan berlangganan banyak vendor data eksternal.

### 2. Morningside AI
* Website: https://morningside.ai/
* Kontak atau Founder: Liam Ottley (Founder), info@morningside.ai
* Wilayah Operasional: Selandia Baru dan Global
* Spesialisasi: Pengembangan AI kustom, strategi implementasi LLM korporat, multi agent systems, dan otomasi alur kerja tingkat lanjut.
* Tech Stack Utama: LangChain, LlamaIndex, Python, n8n, Make, Flowise
* Potensi Use Case Apizie: Morningside AI memproduksi agen otonom tingkat tinggi yang membutuhkan validasi fakta waktu nyata dari berbagai basis data publik. Apizie menyederhanakan akses ke beragam sumber data eksternal melalui REST API dan protokol MCP, memangkas siklus pengembangan Proof of Concept bagi klien tanpa beban pengelolaan akun API terpisah.
